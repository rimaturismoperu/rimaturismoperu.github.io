# Rimaturismo Perú — etapa 3 final

La web y el panel ya están construidos. No vuelvas a crear Cloudflare Pages, el Worker, el token ni las credenciales: solamente reemplaza los archivos del repositorio siguiendo `ENTREGA-ETAPA-3.md`.

## Dirección que debe compartir el cliente

<https://rimaturismoperu.pages.dev/>

La antigua copia de GitHub Pages puede permanecer despublicada. El repositorio de GitHub **no se debe borrar**, porque guarda la página y permite que el panel publique los cambios.

## Panel administrativo

Dirección:

<https://rimaturismoperu.pages.dev/admin/>

El panel conserva las funciones instaladas:

- agregar, editar y eliminar tours;
- cambiar descripciones, horarios y precios;
- ocultar el precio de una experiencia;
- subir, ordenar o eliminar fotografías;
- cambiar WhatsApp y correo;
- publicar automáticamente en Cloudflare Pages.

El Worker ya está conectado en `admin/config.js`. No cambies esa dirección y nunca pongas contraseñas o tokens dentro de los archivos públicos.
